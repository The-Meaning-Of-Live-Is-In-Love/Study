Абстрактные типы данных

  • Модульную программу легче писать, читать и модифицировать,
  • Перед реализацией каждого модуля описывайте его спефицикацию,
  • Скрывайте детали внутреннего устройства модуля от других модулей.

Принцип сокрытия информации (information hiding)

Типичные операции над данными

  • Добавление (add) данных в набор,
  • Удаление (remove) данных из набора,
  • Проверка (ask question) данных, содержащихся в наборе.

Абстракция данных (data abstraction)

  • Функциональная абстракция и абстракция данных сводятся к вопросу — «что?» — а не — «как?» —
  • Абстрактный тип данных состоит из данных и набора операций над ними,
  • В спецификациях указывается, что делают операции, но не описывается их реализация,
  • Структура данных является частью реализации АТД,
  • Тщательно описывайте операции АТД перед их реализацией.

Структура данных является частью реализации АТД

  • Нужна структура данных, в которой одновременно хранятся имена и размер окладов группы сотрудников. Данную структуру можно описать на языке «C++»

const int Max_Number = 500;

string Names[Max_Number];

double Salaries[Max_Number];

Абстрактные типы данных и структуры данных

  • Абстрактный тип данных — совокупность данных и операций над ними.
  • Структура данных — конструкция, определённая в языке программирования для хранения набора данных.
  • Данные понятия отличаются друг от друга.

Программа не должна зависеть от деталей реализации абстрактных типов данных

Спецификации абстрактных типов данных

  • Абстрактный список

Операции над абстрактным списокм

  1. Создать пустой список
  2. Уничтожить список
  4. Определение на пустоту списка
  5. Определение количества элементов в списке
  6. Вставка элемента в указанную позицию списка
  7. Удаление элемента, находящегося в указанной позиции списка
  8. Просмотр (извлечение) элемента, находящегося в указанной позиции списка

Для обращения к элементу списка используется номер его позиции

Псевдокод операций над абстрактным списком

// Элементы списка имеют тип «ListItemType»

+createList()

// Создаёт пустой список

+destroyList

// Уничтожает список

+isEmpty():boolean{query}

// Определяет, пусти ли список

+getLength():integer{query}

// Возвращает количество элементов, содержащихся в списке

+insert out (in index:integer, in newItem:ListItemType, success:boolean)

// Вставляет элемент «newItem» в список на позицию «index» при условии — 1 <= index <= getLength() + 1. index <= getLength() — элементы перенумеровываюися на позицию «index + 1», элемент с которой — «index + 2» и так далее. Признак «success» отмечает, успешно ли выполнена вставка.
