Вопросы для самопроверки

  • Сформулируйте инвариант цикла.

int index = 0;

int sum = item[0];

while (index < n)

{

++index;

sum += item[index];

} // Конец цикла — «while».

  • Напишите спецификацию, используя язык — «UML» — для функции, вычисляющей сумму первых пяти положительных целых чисел из массива, в котором хранятся произвольные целые числа с количеством — «n».
